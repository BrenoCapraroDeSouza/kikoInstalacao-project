# Kiko Instalações


💻 Site Institucional — Empresa de Redes de Gás

Este projeto é um site desenvolvido para uma empresa especializada em instalações e manutenções de redes de gás, além da revenda de produtos como fogões, aquecedores e acessórios relacionados.
O objetivo do site é oferecer uma presença digital profissional, destacando os serviços oferecidos, produtos à venda e facilitando o contato com os clientes.

🚀 Funcionalidades principais:

Apresentação institucional da empresa
Catálogo de produtos (fogões, aquecedores, etc.)
Botão de contato para orçamentos e suporte

🛠️ Tecnologias utilizadas:
HTML, CSS, JavaScript, React, Vite
